Maxik Privacy Policy

Effective date: 18 November 2026. Home

Who uses Maxik

Maxik is a private personal assistant used only by its owner. It is not offered to other people and has no sign-up.

What Google data Maxik accesses

With the owner's explicit consent, Maxik accesses the owner's Google Tasks: task lists and the tasks in them (titles, notes, due dates, completion status). It requests the Google Tasks scope only.

How the data is used

The data is used only to carry out the owner's own requests: to show tasks, add tasks, mark them as completed and delete them. Text of the tasks involved in a request may be processed by the AI model provider that powers the assistant, solely to produce the answer to that request.

Storage and sharing

Access tokens are stored on the owner's private server with access restricted to the owner. Google Tasks data is not sold, not used for advertising, and not shared with third parties other than the processing described above. Maxik does not build a separate copy of the owner's task database.

Limited Use

Maxik's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke Maxik's access at any time at myaccount.google.com/permissions. Stored tokens are deleted from the server when access is no longer needed.

Contact

Questions about this policy can be sent through the Issues page of the GitHub repository that hosts this site.

Политика конфиденциальности Maxik

Действует с 18 ноября 2026 года.

Кто пользуется Maxik

Maxik: личный помощник, которым пользуется только его владелец. Другим людям он не предлагается, регистрации нет.

К каким данным Google есть доступ

С явного согласия владельца Maxik получает доступ к его Google Tasks: спискам дел и делам в них (названия, заметки, сроки, отметки о выполнении). Запрашивается только право доступа к Google Tasks.

Как данные используются

Данные используются только для выполнения просьб самого владельца: показать дела, добавить дело, отметить выполненным, удалить. Текст дел, участвующих в просьбе, может обрабатываться поставщиком модели ИИ, на которой работает помощник, исключительно для ответа на эту просьбу.

Хранение и передача

Токены доступа хранятся на личном сервере владельца, доступ к ним есть только у него. Данные Google Tasks не продаются, не используются для рекламы и не передаются третьим лицам, кроме обработки, описанной выше. Отдельной копии базы дел Maxik не ведёт.

Отзыв доступа и удаление данных

Владелец может отозвать доступ Maxik в любой момент на странице myaccount.google.com/permissions. Сохранённые токены удаляются с сервера, когда доступ больше не нужен.

Связь

Вопросы по этой политике можно задать на странице Issues репозитория GitHub, где размещён этот сайт.
