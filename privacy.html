Maxik Privacy Policy

Effective date: 19 November 2026. Maxik home page

This Privacy Policy explains how the Maxik app ("Maxik", "the app") accesses, uses, stores, shares and deletes information, including Google user data. Maxik is a private personal assistant app that manages its owner's to-do list in Google Tasks.

1. Who uses Maxik

Maxik is used by one person, its owner, with the owner's own Google account. It is not offered to the public and has no sign-up. In this policy "the user" means that owner.

2. Data Maxik accesses

Google user data. With the user's explicit consent on the Google consent screen, Maxik accesses the user's Google Tasks data through the Google Tasks API, using the single scope https://www.googleapis.com/auth/tasks. This data consists of:

  • task lists: their names and identifiers;
  • tasks: titles, notes, due dates, completion status and identifiers.

Authorization data. Maxik stores the OAuth access token and refresh token issued by Google so that it can keep working without asking the user to sign in again.

Data Maxik does not access. Maxik does not access Gmail, Google Drive, Google Calendar, Google Photos, contacts, location, payment information or the Google account password. Maxik does not use cookies, analytics or advertising trackers. This website does not collect personal data from its visitors.

3. How Maxik uses the data

Google Tasks data is used only to provide the app's user-facing features, at the user's own request:

  • to show the user their task lists and tasks;
  • to add a task;
  • to mark a task as completed;
  • to delete a task.

Maxik does not use Google user data for advertising, profiling, market research, or to develop, improve or train generalized artificial intelligence or machine learning models.

4. How the data is processed by AI

Maxik is an AI assistant. When the user asks about their tasks, the text of the tasks involved in that request is sent to the AI model provider that powers the assistant, solely to produce the answer to that request. The provider acts as a data processor for this purpose. Google user data is not used to train AI models.

5. Sharing and disclosure

Maxik does not sell Google user data and does not transfer it to third parties, except:

  • to the AI model provider, as described in section 4, as necessary to provide the app's features;
  • when required by applicable law.

No human other than the user reads the user's Google Tasks data.

6. Storage and security

OAuth tokens are stored in a file on the user's own private server. The file is readable only by the app's service account, and access to the server is limited to the user through encrypted connections (SSH). All requests to Google APIs use HTTPS. Maxik does not keep a separate copy of the user's task database: tasks are read from Google when a request is made.

7. Retention and deletion

OAuth tokens are kept until the user revokes access or stops using the app; then they are deleted from the server. Task text that appeared in a conversation with the assistant may remain in the assistant's conversation history on the user's private server until the user deletes that history.

The user can at any time:

  • revoke Maxik's access to Google data at myaccount.google.com/permissions;
  • delete the stored tokens and conversation history from the server;
  • request deletion of data through the contact below.

8. Google API Services User Data Policy

Maxik's use and transfer of information received from Google APIs to any other app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

9. Children

Maxik is not directed to children and is not used by them.

10. Changes to this policy

If this policy changes, the new version is published on this page with a new effective date.

11. Contact

Questions and requests about this policy can be sent through the Issues page of the Maxik repository.
